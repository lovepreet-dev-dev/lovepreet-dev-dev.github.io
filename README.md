# lovepreet-dev-dev.github.io

GitHub Pages user site. It exists for two reasons:

- `google2b5285ea8f32dfd6.html` proves ownership of `https://lovepreet-dev-dev.github.io/`
  in Google Search Console (needed for Google OAuth branding verification of the
  Remindly app). **Never delete or rename it.**
- `index.html` forwards visitors from the domain root to the portfolio at `/portfolio/`.

Do not add a `portfolio/` folder here: it would hide the portfolio project site.
